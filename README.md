# RosterLab

RosterLab is a one-page team-number artwork builder. Upload a team logo, enter
player last names and jersey numbers, set the team colors, and export an
individual design as a high-resolution PNG or editable SVG.

Logo files and roster data stay in the browser. The deployed app does not store
uploads or player information.

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Use `npm run build` to produce the deployable site.
